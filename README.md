# 三島カメラ 電源監視ダッシュボード（Web版・GitHub Pages + GitHub Actions）

このフォルダ一式を GitHub の**公開(Public)リポジトリ**にアップロードするだけで、
無償で常時公開できるダッシュボードになります。

- データ取得は **GitHub Actions** が5分間隔(ベストエフォート)でサーバー側で自動実行します。
  ブラウザを閉じていても取得は止まりません。
- 取得結果は **GitHub Pages** で公開される静的サイトからそのまま読み込まれるので、
  どのパソコン・スマートフォンから見ても同じ最新データ・同じ履歴が表示されます。
- 追加費用は一切かかりません(GitHub Actions は Public リポジトリなら実行時間無制限で無料)。

## セットアップ手順

1. **GitHubアカウントを作成(お持ちでなければ)** → https://github.com/ にアクセスしてサインアップしてください。
2. **新しいリポジトリを作成**します。右上の「+」→「New repository」。
   - Repository name: 例 `mishima-power-dashboard`
   - **Public** を選択(Actionsの無料枠を使うため)
   - 「Add a README file」はチェックを外してOK(このフォルダに既にREADMEがあります)
3. **このフォルダの中身をすべてアップロード**します。方法はどちらでも構いません。
   - **Web UIで簡単に**: 作成したリポジトリのページで「Add file」→「Upload files」を開き、
     このフォルダの中身(`index.html`、`data/`フォルダ、`scripts/`フォルダ、`.github/`フォルダ、
     この`README.md`)をまとめてドラッグ&ドロップし、「Commit changes」。
     ※ `.github` のような「.」で始まるフォルダも中身ごとドラッグすれば問題なく認識されます。
   - **gitコマンドに慣れている場合**:
     ```
     git init
     git add .
     git commit -m "初回コミット"
     git branch -M main
     git remote add origin https://github.com/<あなたのユーザー名>/mishima-power-dashboard.git
     git push -u origin main
     ```
4. **GitHub Actions にリポジトリへの書き込み権限を与えます**(データ自動保存に必要)。
   リポジトリの Settings → Actions → General → 一番下の「Workflow permissions」で
   **「Read and write permissions」** を選択して Save。
5. **GitHub Pages を有効化**します。
   リポジトリの Settings → Pages → 「Build and deployment」の Source で
   **「Deploy from a branch」** を選び、Branch を **`main` / `/(root)`** に設定して Save。
   数分後、ページ上部に公開URL(`https://<あなたのユーザー名>.github.io/mishima-power-dashboard/`)が
   表示されます。これが常時アクセスできるダッシュボードのURLです。
6. **データ取得を1回手動実行して確認**します。
   リポジトリの「Actions」タブ →「三島カメラ電源データ取得」ワークフローを選択 →
   右側の「Run workflow」ボタンで手動実行できます。数十秒〜1分程度で完了し、
   `data/history.csv` などが自動更新されてコミットされます。
7. 手順5のURLをブラウザで開けば、データが表示されます(手順6の実行完了後)。
   以後は毎5分ごとに自動でデータが更新され続けます。

## 日常の使い方

- 上記URLをブックマークしておけば、どのパソコン・スマートフォンからでも同じ内容が見られます。
- 画面は約1分ごとに自動でサーバーの最新データを再読み込みします。
- 「表で表示」で全期間の記録一覧を、「CSV全履歴をダウンロード」で `data/history.csv`
  (全期間・全拠点のCSV)をそのままダウンロードできます。
- グラフは直近24時間分のみを表示します(全期間の記録はCSV・表からご確認ください)。

## 知っておいていただきたい制限・注意点

- **公開リポジトリのため、PV/BAT電圧の数値・画像URLなどダッシュボードに表示される情報は
  誰でも閲覧可能な状態になります**(パスワード等の機密情報は扱っていません)。
- GitHub無料枠のスケジュール実行は「ベストエフォート」です。混雑時は実際の取得間隔が
  5分より数分〜十数分程度延びることがあります。
- リポジトリへのコミットが60日間まったく発生しないと、GitHubが自動でスケジュール実行を
  無効化する仕様があります。本ワークフローは動作していれば5分ごとにコミットが発生するため
  通常は問題になりませんが、万一「Actions」タブでワークフローが停止していた場合は、
  Actionsタブから該当ワークフローを開き「Enable workflow」で再度有効化してください。
- `data/history.csv` は全期間分を追記し続けるため、運用が長期間になるとファイルサイズと
  リポジトリの容量が徐々に増えていきます。数年単位で運用される場合は、古いデータを
  別ファイルへ移す、あるいはデータベースへ移行するなどの対応をご検討ください
  (現時点では特に対応は不要です)。
- File System Access APIによるローカルの履歴ファイル連携機能は、この構成では
  不要になったため削除しています(履歴は常にサーバー側=GitHubリポジトリに記録されます)。
