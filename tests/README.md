# テスト一式

三島市 河川カメラ・水位ダッシュボードの自動テストです。
**テスト用にコピーしたファイルではなく、リポジトリ直下の本番ファイルそのもの**
(`index.html` と `scripts/poll.mjs`)を対象に検証します。

- ブラウザ側のテストは Playwright(Chromium)で `index.html` を実際に読み込み、
  外部サイトへの通信はすべてモックに差し替えて実行します。ネットワーク接続は不要で、
  実行時刻(昼／夜)にも結果が左右されないようになっています。
- サーバー側のテストは `scripts/poll.mjs` を一時ディレクトリへ複製して実行します
  (`poll.mjs` は読み込まれた時点で自動実行され、1つ上の階層の `data/` へ書き込むため、
  リポジトリの `data/` を汚さないようにするためです)。

## 実行方法

```bash
cd tests
npm install          # playwright と Chromium を取得(初回のみ)
npm test             # 全テストを実行
```

個別に動かす場合:

```bash
cd tests
node test_core.mjs            # 単体で実行
node run_all.mjs power views  # スイートを指定して実行
```

ポート 8971 を使います。使用中の場合は `TEST_PORT=9000 npm test` のように変更できます。

## 構成

| ファイル | 内容 |
| --- | --- |
| `run_all.mjs` | 全スイートの一括実行と集計 |
| `harness.mjs` | ブラウザ起動・外部通信のモック・フィクスチャ生成・合否集計 |
| `server.mjs` | リポジトリ直下を配信するテスト用の静的サーバー |
| `fake-leaflet.js` | 地図ライブラリ(Leaflet)の最小代替。生成された地図・マーカーを検査できる |
| `test_core.mjs` | 拠点カタログ・純粋関数(バッテリー換算 / 電源CSV解析 / 気象庁時刻 / グラフ座標 / 最小二乗法) |
| `test_power.mjs` | 電源監視ビュー(23拠点のカード・残量%・発電W・Range取得・プロキシ退避) |
| `test_forecast.mjs` | 未来予測(気象データ取り込み・水位/バッテリー/発電の予測・点線描画)、水位変化グラフ一覧(直近12時間＋6時間先の予測・右上のカメラ映像) |
| `test_views.mjs` | 画面切り替え・地図の「初期表示に戻す」ボタン・ナウキャスト予測再生の時刻 |
| `test_playback.mjs` | タイムラプス(直近2日・一覧の再生・拠点詳細の再生) |
| `test_history.mjs` | サーバー保存データ(`data/recent.csv` / `data/recent_water.csv`)の解釈と統合 |
| `test_poll.mjs` | `scripts/poll.mjs` の動作(CSV出力・latest.json・画像保持期間・中継サーバー障害時) |

## 主な検証項目(実装の経緯との対応)

- **Phase L**: 取得間隔10分(提婆・神川・徳倉の3拠点のみ2分)、タイムラプスは直近2日、
  発電(PV)は中継サーバー `mini.lhlab-vps.net` の**電力(W)**、12時間先までの予測を点線で表示。
  発電の単位が電圧(V)から電力(W)へ変わったため、**中継サーバー由来の行だけをPV(W)として採用**し、
  それ以前の行のPV値は捨てていることも確認しています。
- **Phase M**: バッテリー残量(%)の電池マーク表示、ナウキャスト予測再生の時刻(UTC→ローカル)、
  全地図の「初期表示に戻す」ボタン、グラフの時刻から秒を除去。
- **Phase N**: ライブカメラ一覧のタイムラプス(同時再生は1拠点のみ)、
  桜川(cam42)の発電(中継サーバー側の名称は**「白滝公園」**)。
- **Phase O**: 予測が最新の実測値からの続きになること(予測キャッシュを最後の実測点に紐づけ、
  変化量を実際の経過時間に比例させる)。
- **Phase P**: バッテリー残量の換算(12.7V=100% / 既定の下限11.5V。
  北沢アンダーパス9.5V、多呂樋管・梅名樋管2号・芝橋10.5V)。
- **Phase Q**: 電源監視の拠点が23拠点(こも池・竹倉用水路・ほたるの里を追加)。
- **Phase S**: 水位変化グラフ一覧のグラフを「現在時刻の12時間前まで(実線)＋6時間先の予測(点線)」に変更し、
  各カードの右上に拠点のカメラ映像を配置。

## テストの追加・修正について

- ダッシュボード本体は `window.__dashboardDebug` にテスト用のフック(内部関数・定数)を公開しています。
  新しい機能を追加する際は、検証したい関数をここへ足してからテストを書くのが簡単です。
- Playwright の `page.route()` は**後に登録したものが優先**されます。`harness.mjs` では
  この性質に合わせて、`r.jina.ai`(URLの中に本来の取得先を含む)や `targetTimes_*.json`
  (ナウキャストのタイル画像と同じ階層)を後ろに置いています。順序を入れ替えるとモックが効かなくなります。
- テストが実行時刻に依存しないよう、気象フィクスチャの日射量は「現在時刻からの相対時間」で生成しています
  (実行が夜間だと過去の日射量が全て0になり、発電の回帰が成立しなくなるため)。
